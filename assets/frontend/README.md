# Frontend assets

These files are only for the settings screen. They are not game or ROM assets.

The generic SVG icons and the Noto Emoji / promptfont fonts came from the `assets/`
folder in Zelda64Recomp revision `1a9c26613c6e0906140dc8bcca7362cbe00bf1eb`:
https://github.com/Zelda64Recomp/Zelda64Recomp/tree/1a9c26613c6e0906140dc8bcca7362cbe00bf1eb/assets

The source project's generic UI artwork is GPL-3.0, which matches this repository's
LICENSE. Keyboard, Cont, PlusKeyboard, RecordSpinner, Caret, and Question are simple
icons added for this menu. `recomp.rcss` selects the shared menu font. RecompFrontend
provides the rest of the menu styling.

The fonts keep their SIL Open Font License. See `NotoEmoji-LICENSE.txt`,
`promptfont/LICENSE.txt`, and `Lato-LICENSE.txt`. The Noto license is at
https://github.com/googlefonts/noto-emoji/blob/main/fonts/LICENSE . LatoLatin regular/bold
are copied during the build from the pinned RmlUi samples and are not stored here.
